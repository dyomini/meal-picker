## 용도별로 후보가 달라집니다

같은 음식이라도 상황에 따라 후보에 오르기도 하고 자동으로 빠지기도 합니다.

| 상황 | 규칙 | 후보 수 | 이런 게 빠집니다 |
|---|---|---|---|
| 🍻 연구실 회식 | 나눠 먹는 음식 + 1만원 이상 | 116 | 김밥, 라면, 혼밥용 덮밥 |
| 🥢 연구실 식사 | 2.5만원 이하 + 냄새 안 남 + 안주 아님 | 173 | 곱창, 삼겹살, 청국장, 오마카세, 마른안주 |
| 💕 데이트 | 분위기 좋음 + 냄새 안 남 | 71 | 곱창, 닭발, 순대국밥 |
| 🧘 혼밥 | 1인분 주문이 자연스러움 | 125 | 보쌈, 전골, 삼겹살 |
| 🙌 친구랑 식사 | 제한 없음 | 250 | — |

총 **262종** 수록. 디저트류는 기본적으로 빠지며, 필터에서 "디저트도 포함"을 켜면 나옵니다.

### 항목을 굵직하게 잡은 이유

메뉴판에서 실제로 고르는 단위로 묶었습니다. 짜장면/간짜장/삼선짜장처럼 갈래만 다른 건 **짜장면** 하나로, 부채살·토시살·등심 같은 부위는 **소고기구이** 하나로 합쳤습니다. 뭐가 포함되는지는 `foods.js` 의 각 줄 옆 주석에 적혀 있습니다.

```js
f("짜장면", "중식", 1, "solo,lab,heavy"),   // 간짜장·삼선·유니·쟁반짜장
```

더 잘게 나누고 싶으면 줄을 추가하면 됩니다.

규칙을 바꾸고 싶으면 `app.js` 맨 위 `SCENES` 의 `ok:` 한 줄만 고치면 됩니다.

```js
date: {
  ok: d => d.mood && !d.smell,   // ← 여기
},
```

## 제외하는 방법 두 가지

결과 카드 아래 버튼이 두 개 있습니다.

- **이 상황엔 빼줘** — 지금 고른 상황에서만 제외. (곱창은 친구랑은 괜찮은데 데이트엔 아닐 때)
- **아예 안 먹어** — 모든 상황에서 영구 제외.

⚙️ 설정 화면에서 제외 목록 확인·복구, 검색해서 미리 제외하기가 됩니다.

## 음식 추가하기

`foods.js` 의 `FOODS` 배열에 한 줄 추가하면 끝입니다.

```js
f("이름", "카테고리", 가격, "플래그,플래그")
```

- **카테고리** — 한식 중식 일식 양식 아시안 멕시칸 분식 고기 술안주 카페
- **가격** — `1` 만원 이하 / `2` 1~2.5만원 / `3` 2.5만원 이상
- **플래그** — `solo` `share` `mood` `date` `booze` `smell` `lab` `sea` `veg` `spicy1~3` `heavy` `light` `dessert`
  (자세한 설명은 `foods.js` 맨 위 주석에 있습니다)

예시:
```js
f("연어포케", "양식", 2, "solo,lab,sea,mood,light"),
```

> ⚠️ **이미 있는 음식의 이름은 바꾸지 마세요.** 제외 기록이 음식 이름으로 저장되기 때문에,
> 이름을 바꾸면 그 음식의 제외 기록이 풀립니다.

## 폰에서 쓰기 (GitHub Pages)

이 폴더는 이미 git 저장소로 초기화되어 있고 첫 커밋도 되어 있습니다. 아래만 하면 됩니다.

**1. GitHub에서 빈 저장소 만들기**
[github.com/new](https://github.com/new) → 이름 `meal-picker` → **Public** → README·.gitignore 체크 해제 → Create

**2. 올리기** (이 폴더에서)
```bash
git remote add origin https://github.com/<내아이디>/meal-picker.git
git push -u origin main
```

**3. Pages 켜기**
저장소 → Settings → Pages → Source: **Deploy from a branch** → Branch: `main` / `(root)` → Save

1~2분 뒤 아래 주소로 열립니다.
```
https://<내아이디>.github.io/meal-picker/
```

**4. 폰 홈 화면에 추가**
- **안드로이드(Chrome)**: 주소창 우측 ⋮ → "앱 설치" 또는 "홈 화면에 추가"
- **아이폰(Safari)**: 공유 버튼 → "홈 화면에 추가"

추가하면 주소창 없이 앱처럼 뜨고, **비행기 모드에서도 동작**합니다(서비스 워커가 파일을 캐시함).

### 수정한 걸 폰에 반영하기
```bash
git add -A
git commit -m "음식 추가"
git push
```
푸시하고 1분쯤 뒤 폰에서 앱을 껐다 켜면 갱신됩니다. (네트워크 우선 캐시라 온라인이면 항상 최신)

### 주의
- GitHub Pages는 **공개 주소**입니다. 주소를 모르면 찾기 어렵지만, 비밀은 아닙니다.

## 기기 간 동기화 (선택)

설정하면 PC에서 뺀 음식이 폰에도 자동으로 반영됩니다. 안 해도 앱은 정상 동작하며, 이때는 기기마다 목록이 따로 저장됩니다.

### 1. Firebase 데이터베이스 만들기 (5분, 무료)

1. [console.firebase.google.com](https://console.firebase.google.com) → **프로젝트 만들기** (이름 아무거나, 애널리틱스는 꺼도 됨)
2. 왼쪽 메뉴 **빌드 → Realtime Database** → **데이터베이스 만들기**
3. 위치는 `asia-southeast1` 선택 → 보안 규칙은 **잠금 모드**로 시작
4. **규칙** 탭으로 가서 아래로 통째로 교체하고 **게시**

```json
{
  "rules": {
    "sync": {
      "$key": {
        ".read": "$key.length >= 24",
        ".write": "$key.length >= 24"
      }
    }
  }
}
```

> 이 규칙은 "24자 이상의 코드를 정확히 아는 경우에만 그 칸을 읽고 쓸 수 있다"는 뜻입니다.
> 데이터베이스 전체를 훑거나 목록을 뽑는 건 막혀 있습니다.

5. **데이터** 탭 맨 위에 있는 주소를 복사 (`https://...firebasedatabase.app`)

### 2. 주소 넣고 배포

`config.js` 를 열어 한 줄만 고칩니다.

```js
const SYNC_DB_URL = "https://내프로젝트-default-rtdb.asia-southeast1.firebasedatabase.app";
```

```bash
git add -A && git commit -m "동기화 설정" && git push
```

### 3. 기기 연결

1. PC에서 앱 → ⚙️ → **기기 간 동기화** → **내 동기화 코드** 복사
2. 폰에서 앱 → ⚙️ → 코드 붙여넣고 **이 코드로 연결**

끝입니다. 이후로는 어느 쪽에서 음식을 빼든 다른 기기에 자동 반영됩니다. 앱을 열 때, 화면을 다시 볼 때, 인터넷이 돌아올 때 자동으로 확인합니다.

### 알아둘 것

- **코드가 곧 열쇠입니다.** 이 코드를 아는 사람은 목록을 보고 고칠 수 있으니 아무 데나 올리지 마세요.
- **동시에 고치면 나중에 고친 쪽이 이깁니다.** PC와 폰에서 같은 시각에 서로 다른 음식을 빼면 한쪽이 덮어써집니다. 혼자 쓰는 앱이라 실제로 겪을 일은 거의 없습니다.
- **오프라인에서도 앱은 정상입니다.** 업로드만 실패하고 로컬에는 저장되며, 인터넷이 돌아오면 다시 맞춥니다.
- 동기화를 켜도 **백업 기능은 그대로** 쓸 수 있습니다.
